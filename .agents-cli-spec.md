# Agent Spec

## Overview
Creative Director AI is a TypeScript ADK swarm that turns a music-video brief into a genre-aware treatment and beat-synced storyboard, then (in production mode, after explicit render approval) calls existing Veo + Pixels + C2PA tools. Writer, DP, and Editor are in-process specialists with committed A2A Agent Cards; the director delegates rather than writing Veo prompts itself.

## Example Use Cases
- Planning: “Storyboard a 30s dark synthwave intro at 120 BPM” → `select_genre_pack` → deep dark-pop → writer treatment → DP storyboard; no GCS URLs.
- Planning: “boom-bap hip-hop on night streets” → hip-hop pack named in the reply.
- Planning: “shoegaze dream video” → family template (non-deep catalog hit) with `source: template`.
- Production after “approved / render it”: DP prompts feed `generate_video_cut`, editor args feed `assemble_and_sync_timeline` then `sign_c2pa_manifest`.

## Tools Required
- `select_genre_pack` — local function; no auth.
- `writer_agent` / `dp_agent` / `editor_agent` — AgentTool (local) or `RemoteA2AAgent` when `WRITER_A2A_CARD_URL` / `DP_A2A_CARD_URL` / `EDITOR_A2A_CARD_URL` is set (A2A card JSON URL).
- `search_specialist` / `url_specialist` — Google Search / URL context (same as before).
- `generate_video_cut`, `assemble_and_sync_timeline`, `sign_c2pa_manifest` — Vertex + GCS + Pixels as already configured; unchanged.
- Grafana Cloud MCP (`MCPToolset`) when `GRAFANA_URL` or `GRAFANA_MCP_URL` is set — query Loki/Tempo/Prometheus for render failures, latency, and pipeline health (tools prefixed `grafana_`).

## Constraints & Safety Rules
- Planning mode never claims a render, assembly, or C2PA signature and never invents GCS URLs.
- Production waits for explicit render approval before Veo unless the user already said to render.
- Do not quote copyrighted lyrics verbatim.
- Mock tool results stay labeled mock.

## Success Criteria
- Existing eval cases still pass (`storyboard_120bpm`, `research_visual_refs`, `no_fake_asset_urls`).
- `writer_dp_package_shape` yields genre + treatment + scene fields without URLs.
- `genre_skill_hip_hop` names the hip-hop pack.
- `planning_no_render_claims` refuses GCS/C2PA claims (`no_fake_asset_urls` = 1.0).
- Unit tests cover genre routing, skill load, agent cards, and package schema.

## Architecture & Sub-Agents
Coordinator: `Creative_Director_AI` (`planning` | `production` via `CREATIVE_DIRECTOR_MODE`).
Specialists: `writer_agent`, `dp_agent`, `editor_agent` (A2A cards in `agents/cards/`).
Function tools stay on the director. Film/sitcom are out of scope.

## Assumptions
- HITL before Veo unless the user explicitly approves rendering.
- Hybrid genre catalog: ~25 deep packs + family templates for other Apple/Spotify aliases; generic craft fallback.
- Model remains `gemini-3.5-flash` at `location: "global"`.
- TypeScript A2A serving via `toA2a` is a follow-on if Agent Runtime does not expose JSON-RPC for this app.
